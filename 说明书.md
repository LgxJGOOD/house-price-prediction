## 1. 项目概述

### 1.1 项目简介
本项目是一个基于Django+Vue的二手房房价预测与分析系统，集成了机器学习模型进行房价预测、数据可视化分析、用户管理等功能。

## 5. 后端功能详解

### 5.1 用户认证模块

#### 5.1.1 注册功能 (RegisterUserAPIView)

**原理**: 使用Django REST Framework的ModelSerializer进行数据验证

```python
# 核心验证逻辑
def validate(self, attrs):
    # 1. 验证两次密码一致
    if attrs['password'] != attrs['password2']:
        raise serializers.ValidationError({"code": 400, "message": "Password fields didn't match."})

    # 2. 验证密码长度
    if len(attrs['password']) < 3:
        raise serializers.ValidationError({"code": 400, "message": "Password must be at least 3 characters long."})

    return attrs

# 创建用户 - 使用create_user自动哈希密码
def create(self, validated_data):
    role_id = self.initial_data.get('role_id', None)
    validated_data.pop('password2')
    user = User.objects.create_user(**validated_data)
    if role_id is not None:
        user.role_id = int(role_id)
        user.save()
    return user
```

**技巧**:
- `create_user()` 方法自动调用 `set_password()` 哈希密码
- 使用 `initial_data` 获取原始请求数据(因为 `validated_data` 已移除password2)

#### 5.1.2 登录功能 (LoginAPIView)

**原理**: 使用Django认证系统和JWT令牌

```python
def validate(self, data):
    # authenticate() 内部调用 User.objects.get_user() 获取用户
    # 然后调用 user.check_password(raw_password) 验证密码
    user = authenticate(**data)
    if not user or not user.is_active:
        raise serializers.ValidationError({
            "code": 400,
            "message": "用户名不存在或用户已停用."
        })
    return user

# 登录成功后生成JWT令牌
def post(self, request, *args, **kwargs):
    # ...验证通过后...
    refresh = RefreshToken.for_user(user)
    return Response({
        'refresh': str(refresh),
        'access': str(refresh.access_token),
        'user': UserSerializer(user).data
    })
```

**JWT令牌结构**:
- `RefreshToken`: 包含 user_id, exp, iat, jti
- `AccessToken`: 包含 user_id, exp, iat, token_type

**技巧**:
- `RefreshToken.for_user(user)` 创建令牌时会将用户ID嵌入token
- `BLACKLIST_AFTER_ROTATION=True` 确保登出时令牌被加入黑名单

### 5.4 文件上传

#### 5.4.1 图片上传处理

```python
class UploadImgView(APIView):
    def post(self, request):
        rev_file = request.FILES.get('file')
        if not rev_file:
            return Response({"code": 400, "message": '文件不存在'}, status=400)

        # 生成唯一文件名: UUID + MD5哈希
        new_name = self.get_random_str()
        ext = os.path.splitext(rev_file.name)[1]  # 保留原扩展名
        file_path = os.path.join(settings.UPLOAD_FILE, new_name + ext)

        # 分块写入文件，避免大文件内存溢出
        with open(file_path, 'wb') as f:
            for chunk in rev_file.chunks():
                f.write(chunk)

        return Response({"code": 200, "data": r'http://127.0.0.1:8899/upload/'+new_name + ext})

    @staticmethod
    def get_random_str():
        uuid_val = uuid.uuid4()
        uuid_str = str(uuid_val).encode('utf-8')
        md5_obj = hashlib.md5()
        md5_obj.update(uuid_str)
        return md5_obj.hexdigest()
```

**技巧**:
- `rev_file.chunks()` 分块读取，避免大文件内存溢出
- UUID + MD5 生成唯一文件名，防止文件名冲突
- `os.path.splitext()` 保留原文件扩展名

## 附录

### A. 关键技术点总结

1. **JWT认证流程**: 登录获取refresh/access token -> 请求带Bearer token -> 过期用refresh换access
2. **密码安全**: 使用Django的`make_password`和`check_password`，不存储明文
3. **图片处理**: 分块读写避免内存溢出，UUID+MD5生成唯一文件名
4. **数据可视化**: Pandas处理数据 -> ECharts渲染图表
5. **机器学习**: 随机森林回归 -> 特征编码 -> 模型训练 -> 预测

### B. 常见问题

1. **跨域问题**: 启用corsheaders中间件
2. **JWT过期**: 前端使用refresh token重新获取access token
3. **图片404**: 检查UPLOAD_FILE路径和静态文件服务配置
4. **预测失败**: 检查模型文件和编码器是否存在
